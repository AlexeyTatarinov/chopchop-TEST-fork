# BUG-20261118-01: Камера вращается при движении мыши без зажатой правой кнопки (по данным AltTester)

- Статус: Не подтверждено
- Проверка: CHK-04
- Severity: S3
- Priority: P2
- Воспроизводимость: 3 из 3 (только при эмулированном вводе через AltTester; ручная проверка реальной мышью не выполнялась)
- Дата и время: 2026-11-18, около 22:57–23:00
- Компонент: движение

## Окружение
- Игра: Chop Chop, коммит 7c588371 (ветка claude/alttester-cli-connection-9050ce)
- Unity: 6.3 LTS (6000.3.28f1)
- Режим: Editor Play Mode
- ОС: Windows 11
- Сцена: Beach (персонаж на стартовом острове)

## Шаги воспроизведения
1. Запустить игру, выбрать New Game, дождаться сцены Beach.
2. Записать положение камеры относительно персонажа.
3. Выполнить `alttester move-mouse --x 553 --y 189 --duration 0.1`.
4. Выполнить `alttester move-mouse --x 753 --y 189 --duration 0.3` (ПКМ не нажимается).
5. Через 1 секунду записать положение камеры.

## Ожидаемый результат
Камера не вращается, пока правая кнопка мыши не зажата (CHK-04: «Камера вращается только при зажатой правой кнопке»).

## Фактический результат
Камера повернулась без зажатой правой кнопки. Угол положения камеры вокруг персонажа (yaw, градусы) до и после, по трём прогонам:
- прогон 1: -39.4 → 11.9
- прогон 2: -8.7 → 76.4
- прогон 3: 53.4 → 91.4

## Доказательства
- Скриншот: `Reports/evidence/r2_CHK-04_before.png`, `Reports/evidence/r2_CHK-04_after.png`
- Видео: нет
- Лог Console: `Reports/evidence/logs/r2_CHK-04.log` (строки «A no-RMB right +200px»; координаты камеры и игрока взяты через `alttester find`)

## Примечания
- Обход проблемы: нет данных.
- Почему выбрана такая severity/priority: по шкале «функция работает с заметным дефектом» это S3; повторяемость 3 из 3 даёт по матрице P2. Статус «Не подтверждено», потому что воспроизведение возможно только через эмулированную мышь.
- Гипотеза (не проверена): в `CameraManager.OnCameraMove` игнорируются движения мыши без ПКМ только если `context.control.device.name == "Mouse"` (`InputReader.IsDeviceMouse`). Если виртуальная мышь AltTester называется иначе, проверка обходится, и движение трактуется как ввод геймпада. Тогда это артефакт инструмента, а не баг игры.
- Нужна проверка человеком: реальной мышью подвигать курсор в игре без ПКМ и посмотреть, вращается ли камера.
- Остальные части CHK-04 с зажатой ПКМ (горизонталь и вертикаль) см. в итоге сессии.
- Похожие issues: не найдено в листе «Известные баги».
